# Contributing

Thank you for contributing to Awesome Half Marathon Training.

## Standards

- All resources must be publicly accessible and relevant to half marathon training, physiology, or racing.
- Training recommendations must cite peer-reviewed evidence or well-established coaching frameworks (Daniels, Pfitzinger, Hudson, Magness).
- Anecdotal training advice without physiological grounding will not be accepted.

## Adding a Resource

1. Fork the repository.
2. Add your resource in the appropriate section.
3. Use the format: `- [Title](URL) — Brief description.`
4. Submit a pull request with a description of why the resource meets the evidence standard.

## Format

- Descriptions should be one sentence.
- For training plans, note the target weekly mileage and goal time range.
- For research, include author and year where space allows.

## Code of Conduct

Be respectful. Focus on accuracy over popularity. Commercial training plans are welcome if they meet the evidence standard — do not add affiliate links without disclosure.
